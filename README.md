# Riding the Color Line: A Spatial Analysis of MARTA Distribution and Racial Segregation in Metro Atlanta

This project asks whether the placement of MARTA rail stations reflects metro Atlanta's history of suburban resistance to the system. Mostly white counties voted it down for decades. Using point pattern analysis, correlation analysis, Moran's I, and Monte Carlo simulation, it finds that stations cluster where more Black residents live, that population density doesn't explain where they are, and that random placement can't account for the pattern.

Final project for DSAN 6750 / PPOL 6805: Geographic Information Systems for Spatial Data Science, Georgetown University, Fall 2025.
